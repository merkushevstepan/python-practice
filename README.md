# python-practice

Мои учебные решения по Python: короткие задачи, лабораторные работы и эксперименты.
Репозиторий показывает, как я учусь, и служит моей личной базой примеров.

## Как организованы файлы

- `fundamentals/` — короткие задачи: условия, циклы, строки, коллекции, функции
- `files_and_errors/` — файлы, JSON/CSV, обработка исключений
- `oop/` — классы, инкапсуляция, композиция
- `labs/` — лабораторные работы: небольшие рабочие задания из нескольких тем
- `sandbox/` — эксперименты и проверка идей

Законченные проекты (боты, приложения) живут в отдельных репозиториях.

## Правила

- Имена файлов описывают задачу: `find_invalid_transactions.py`
- Коммит после логически законченного куска работы
- Никаких паролей, токенов и личных данных
